## What belongs here

Frankensurf is the web substrate. It owns access: routing, providers, pacing,
policy, identities, receipts and evidence. It does not own meaning.

- **No site-specific Python.** Per-site knowledge is data: route seeds in
  `bundled_route_seeds.json`, and route memory. `tests/test_substrate_boundary.py`
  enforces it.
- **No hard-coded limits.** Every stop, budget or allowlist is a
  [WebPolicy](/docs/reference/settings/) field with a default.
- **Everything is a plugin.** New tools go behind the plugin interfaces.
- **Callers interpret.** What a page means (prices, states, rankings) belongs
  in the app or agent calling Frankensurf, which pins a tagged release.
- **Claims need evidence.** A provider counts as working after a live run, not
  after mocked tests.

## Releases

Work on short-lived branches from `main`, merge, and tag a release when a
change should reach consumers. Consumers pin a tag, never a working checkout.
