Frankensurf is an open-source web layer for AI agents. Ask for a URL or a
search, and it picks the right browsing tool for that page, climbs to a stronger
one when the site pushes back, and returns clean page data with a receipt of
how it got there.

- **Every site.** Plain HTTP, real browsers, stealth browsers, unblockers and, as
  a last resort, you. Six rungs, one call.
- **Every agent.** The same tools and the same results on Claude, GPT, Gemini or
  an open-weight model, through MCP, Python or the command line.
- **Shows its work.** Every result says which tools ran, how long each took and
  what it cost.

## Read your first page

No account or key needed.

<Tabs syncKey="lang">
<TabItem label="Python">

```python
from frankensurf import Runtime

async with Runtime("state") as web:
    page = await web.read("https://developers.cloudflare.com/fundamentals/reference/markdown-for-agents/",
                          policy_overrides={"prefer_markdown": True})
    print(page["title"], page["receipt"]["method"])
```

</TabItem>
<TabItem label="CLI">

```bash
frankensurf read https://developers.cloudflare.com/fundamentals/reference/markdown-for-agents/ --markdown
```

</TabItem>

## Why Frankensurf

Every browsing tool breaks somewhere. A model's built-in fetch skips
JavaScript. A browser gets challenged. A stealth browser gets flagged. An
unblocker costs money on pages that never needed it. Frankensurf stitches
[30-plus tools](/docs/integrations/) together and routes each page to the cheapest
one that works, so your agent stops dead-ending.

It returns raw page data, not answers. Your agent has a model; it decides what
the page means.
