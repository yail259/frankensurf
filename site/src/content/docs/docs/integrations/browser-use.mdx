[Browser Use](https://github.com/browser-use/browser-use) 0.13.10 drives a fresh browser with a model you supply. Give it a task and it can click, use search boxes and finish on any page inside its allowed origins.

- Uses your model, through a factory function you own.
- Runs in its own environment and a throwaway browser profile.
- Bounded by steps, model calls, actions and time. A paid model also needs `allow_paid_fallbacks=True`.

## Set up

1. Install the pinned SDK in its own environment:

   ```bash
   python3 -m venv ~/.local/share/frankensurf/agent-venv
   ~/.local/share/frankensurf/agent-venv/bin/python -m pip install -r requirements-browser-use.txt
   ```

2. Write a model factory, for example `/home/you/models/agent.py`:

   ```python
   from browser_use import ChatOpenAI
   from frankensurf.browser_use_binding import ModelBinding

   def create_model():
       return ModelBinding(ChatOpenAI(model="gpt-4.1-mini", max_retries=0), billing="paid")
   ```

3. Point Frankensurf at it:

   ```bash
   export FRANKENSURF_BROWSER_USE_MODEL_FACTORY=/home/you/models/agent.py:create_model
   export FRANKENSURF_BROWSER_USE_BILLING=paid
   ```

## Use it

It runs when a call names it, never as a step of ordinary reads: a model-driven
agent takes tens of seconds a page (about 40 s for a simple page on a local 9B
model), where FrankenSurf's own browsers take a few. Each attempt gets an
agent's time (`agent_provider_timeout_seconds`, 300 s). To use it:

<Tabs syncKey="lang">
<TabItem label="Python">

```python
page = await web.read(
    "https://example.com/products/2231",
    provider="browser_use",
)
```

</TabItem>
<TabItem label="CLI">

Give it a task with `browser_agent_task`:

```python
page = await web.read("https://example.com", provider="browser_use",
    policy_overrides={"browser_agent_task": "find the pricing page and open the Pro plan"})
```
