[Brave Search API](https://brave.com/search/api/) queries Brave's own web index.

- Cost is $0.005 per query by default; set yours with `FRANKENSURF_BRAVE_COST_PER_QUERY`.
- Joins after the free sources when paid tools are allowed.
- Skipped until the key is set.

## Set up

Set `FRANKENSURF_BRAVE_API_KEY`.

## Use it

Ask for this source by name. Named sources never fall back to another.

<Tabs syncKey="lang">
<TabItem label="Python">

```python
from frankensurf import WebPolicy

results = await web.search("playwright python tutorial", source="brave", policy=WebPolicy(allow_paid_fallbacks=True))
```

</TabItem>
<TabItem label="MCP">

```json
{ "tool": "search", "arguments": { "query": "playwright python tutorial", "source": "brave", "acquisition_policy": { "allow_paid_fallbacks": true } } }
```

</TabItem>
