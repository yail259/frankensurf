[Scrapfly](https://scrapfly.io/) renders pages with anti-bot bypass on its own infrastructure.

- Cost is credits used times your rate; unknown until you set it.
- Gets the longer unblocker timeout (90 s).

## Set up

Set `FRANKENSURF_SCRAPFLY_API_KEY` and `FRANKENSURF_SCRAPFLY_USD_PER_CREDIT`.

## Use it

Once its key is set, it joins any read that allows paid tools. To use it on its own:

<Tabs syncKey="lang">
<TabItem label="Python">

```python
page = await web.read(
    "https://example.com/products/2231",
    provider="scrapfly",
    policy_overrides={"allow_paid_fallbacks": True},
)
```

</TabItem>
<TabItem label="MCP">

```json
{ "tool": "read", "arguments": { "url": "https://example.com/products/2231", "provider": "scrapfly", "acquisition_policy": { "allow_paid_fallbacks": true } } }
```

</TabItem>
</Tabs>
