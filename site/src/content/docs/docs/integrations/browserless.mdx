[Browserless](https://www.browserless.io/) serves Chromium over a websocket. Each read connects, renders the page and disconnects.

- Billed in 30-second units.
- Refuses a session that could pass your `max_cost_usd`.
- Point it at another region or a self-hosted Browserless with `FRANKENSURF_BROWSERLESS_URL`.

## Set up

Set `FRANKENSURF_BROWSERLESS_API_KEY`. Default rate $0.24/hour; set yours with `FRANKENSURF_BROWSERLESS_USD_PER_HOUR`.

## Use it

Once its key is set, it joins any read that allows paid tools. To use it on its own:

<Tabs syncKey="lang">
<TabItem label="Python">

```python
page = await web.read(
    "https://example.com/products/2231",
    provider="browserless",
    policy_overrides={"allow_paid_fallbacks": True},
)
```

</TabItem>
<TabItem label="MCP">

```json
{ "tool": "read", "arguments": { "url": "https://example.com/products/2231", "provider": "browserless", "acquisition_policy": { "allow_paid_fallbacks": true } } }
```

</TabItem>
</Tabs>
