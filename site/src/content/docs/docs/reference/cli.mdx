---
title: Command line
description: Every frankensurf command and option.
---

```bash
frankensurf <command> [targets] [options]
```

Output is JSON. The raw page body is left out unless you pass `--raw`. State
goes to `--state` (default `./state`).

## Commands

| Command | Targets | What it does |
| --- | --- | --- |
| `setup` | none | Download Chromium and the free stealth browsers (`--no-stealth` skips them), then check each one starts and reads a page: `works_here` in the result. |
| `read` | one URL | Read a page. `--module ID` uses a site module; `--module none` turns them off. |
| `read-template` | module ID, template | Read a URL built from a site module's template; `--param NAME=VALUE` per parameter. |
| `module` | `list`, `show ID`, `add FILE`, `enable ID`, `disable ID`, `rm ID`, `repair TRACE_ID FILE`, `discover URL [--query TEXT] [--save]` | Manage [site modules](/docs/read/site-modules/); `repair` proposes a fixed version for owner promotion with `repair-promote`; `discover` drafts one from a page's own data. |
| `watch-sites` | site URLs | New pages on those sites from their feeds and sitemaps; `--since DATE`, `--read-new`. |
| `skill` | `install` or `uninstall` (`--skill-dir`), or `show` | Install, remove or print the agent skill (SKILL.md). |
| `plugins` | `list`, `trust KIND ID DISTRIBUTION`, `untrust KIND ID`, `disable KIND ID`, `enable KIND ID` | Third-party [plugins](/docs/more/plugins/): what loaded, what was turned away and why, and the trust file. |
| `egress` | `check` | Whether your direct connection and each [second connection](/docs/blocked/egress/) works, and where it comes out (address, country, WARP). |
| `extract` | one URL | Read through `--adapter` (default `html`). |
| `batch` | URLs | Read several pages. |
| `search` | query words | Search. `--source` picks one source; `--limit` (default 10). |
| `watch` | one URL | One poll for new links; `--link-pattern RE`. |
| `paginate` | one URL | Follow pages; needs `--adapter`; `--max-pages`, `--continuation-adapter`. |
| `images` | image URLs | Download and check images. |
| `trace` | one trace ID | Show how a result was fetched. |
| `compare` | a file of URLs | Read each URL with Frankensurf and with a Firecrawl-compatible endpoint, side by side: `--against URL` (default Firecrawl's cloud), `--against-key`, `--rows FILE`. See [Try it on your URLs](/docs/compare/). |
| `import` | one URL | Store a capture you made: `--evidence-file`, `--observed-at`, `--content-type`. |
| `do` | none | A typed browser action from `--intent-file`; needs `--identity`, `--grant-action`, `--action-origin`. |
| `repair` | one trace ID | Diagnose a retained extract failure; `--repair-policy-file`. |
| `repair-promote`, `repair-disable` | one proposal or overlay ID | Activate (`--proposal-sha256`) or disable (`--disable-reason`) a repair overlay. |
| `executor-enroll` | executor ID | Register a Chrome: `--cdp-url`, `--user-data-dir`, `--profile-directory`, `--network-context`, `--geography`. |
| `identity-enroll` | identity ID | Register a login: `--executor-id`, `--domain`, `--image-domain`, `--auth-url`, `--authenticated-selector`, `--login-selector`, `--allow-action`. |
| `identity-status` | optional identity ID | Health of your identities. |
| `identity-revoke` | identity ID | Remove an identity. |
| `bot-auth-init` | none | Create a Web Bot Auth key. |
| `bot-auth-directory` | none | Print the public key directory to serve. |

## Read options

These map to [WebPolicy](/docs/reference/settings/) fields and work on
`read`, `extract`, `batch`, `watch` and `paginate`.

| Option | Field |
| --- | --- |
| `--provider ID` | `provider` |
| `--provider-candidate ID` (repeat) | `provider_candidates` |
| `--markdown` | `prefer_markdown` |
| `--render` | `render` |
| `--handoff` | `allow_handoff` |
| `--lightning` | `lightning` |
| `--real-browser` | `allow_real_browser` |
| `--paid`, `--max-cost USD` | `allow_paid_fallbacks`, `max_cost_usd` |
| `--capture-json` | `capture_json_responses` |
| `--images`, `--max-images N` | `include_images`, `max_images` |
| `--card-images`, `--scroll-screens N` | `card_images`, `scroll_screens` |
| `--links`, `--max-links N` | `include_links`, `max_links` |
| `--markdown-output` | `markdown_output` |
| `--items`, `--max-items N` | `auto_items`, `max_items` |

`--items` (on `read` and `batch`) returns `items` from a listing page that has no saved
module: one record per repeated card, from the page's own JSON first, else its repeated
HTML rows, else repeated cards in a text-only read's markdown. Each item has `name`, `url`,
and, when the card shows them, `image`, `price`, `was_price`, `currency`, `availability`
(`in_stock`, `out_of_stock`, `limited`, `expired`) and `stock_count`, plus `date`, `rating`
or `location` on pages that carry those. Sponsored entries are left out. `items_quality`
grades the list (`good`, `partial` or `poor`, with a `reason`), and `auto_module` is the
drafted module: save it with `module add` to get the same items on every later read.

A title that names several offers ("Mouse from $129, White $159 (Was $259)") gives the item
`offers`, a list of `label`, `price` and (when that offer shows one) `was_price`. Each offer
pairs only its own prices, and the item's `price` is the offer whose label matches its name,
else the first. Menus, page text and links every page of the site repeats are not items:
a group of cards needs typed fields beyond its links, and when another page of the same
site is already in the read cache, what the two share is left out.

`--items` returns at most 200 items (`--max-items N` sets it, up to 500). A page with more
says so: `items_truncated` is `true` and `items_total` is how many it holds.

```bash
frankensurf read https://shop.example/clearance --items --max-items 500
```

`--schema FILE.json` with `--items` also fills your own fields on each item, as `extracted`
(`data`, `sources`, `missing`). The file is a JSON Schema, or field names to type hints:

```bash
echo '{"role": "title", "salary": "price", "location": "location", "remote": "boolean", "posted": "date"}' > jobs.json
frankensurf read https://jobs.example/search?q=widget --items --schema jobs.json
```

See [Site modules](/docs/read/site-modules/#your-own-fields-on-each-item) for how fields are filled.

`map URL` (`--query`, `--limit`) and `crawl URL` (`--limit`, `--max-depth`, `--include-path`, `--exclude-path`,
`--entire-domain`, `--ignore-robots`): see [Map and crawl](/docs/crawl/).

`ask "question"` (`--model`): agent mode, see [Agent mode](/docs/agent-mode/). `serve --model` turns on the
summary, json and extract endpoints.
| `--expect WORD` (repeat) | `expect_terms` |
| `--freshness now\|hour\|day\|cached` | `freshness` |
| `--timeout S` | `timeout_seconds` |
| `--wait-selector CSS` | `wait_selector` |
| `--content-ready-selector CSS`, `--content-ready-timeout S` | `content_ready_selector`, `content_ready_timeout_seconds` |
| `--agent-task TEXT` | `browser_agent_task` |
| `--identity ID` | `identity` |
| `--max-pages N` | `max_pages` |
| `--provider-max-attempts-per-candidate N`, `--provider-retry-delay S`, `--provider-retry-failure CODE` | retry fields |

Search adds `--search-source-candidate`, `--search-source-allow`,
`--search-source-prefer` (each repeatable), `--search-max-attempts`,
`--search-source-timeout` (0 means the operation timeout) and `--search-url`.

`--paid` allows paid tools whose keys are set (`allow_paid_fallbacks`) and
`--max-cost USD` caps what one operation may spend (`max_cost_usd`). Fields
without a flag are set from Python or MCP.

## Other options

| Option | What it does |
| --- | --- |
| `--state DIR` | State directory (default `state`). |
| `--steel-url URL` | A self-hosted Steel. |
| `--identity-registry PATH` | Identity registry (default `FRANKENSURF_IDENTITIES` or `~/.frankensurf/identities.json`). |
| `--raw` | Include the raw page body. |
